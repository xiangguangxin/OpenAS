# 可复用研究记录 / Reusable research note

只在需要跨任务复用或用户要求保存时写入项目已有研究位置；单个事实回答保留引用即可。为支持决定的问题写简短研究记录：问题、边界/停止条件、结论及适用条件、每条关键结论的原始来源/版本/查阅日期、反例与未知、下一步实验。代码阅读与实际运行分开。复用前核对相关版本和上下文，过期内容保留历史并标记待复验。

Save in the existing project research location when reuse or requested persistence warrants it; a single fact needs only a cited answer. Record the question, bounds/stop condition, conclusions/conditions, primary sources/versions/access dates for material claims, counterexamples, unknowns, and next experiments. Separate source reading from execution. Revalidate versions/context before reuse; preserve stale records as history with explicit recheck needs.

Background agents are optional: use them only with existing authorization, host support, independent work, and a bounded brief. Do not require delegation for a simple question. This adapts the primary-source/repository-note method of Matt Pocock's research skill; [attribution](../../../references/skill-methods/NOTICE.md).
