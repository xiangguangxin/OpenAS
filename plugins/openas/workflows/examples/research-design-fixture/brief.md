# 本地任务交接工具设计输入

用户：小型开发团队。问题：跨会话交接容易丢失未决项与验证证据。
目标：设计一个离线 CLI，将 Markdown 交接记录组织成可检索的项目目录。
约束：Linux / WSL；Python 3.10+ 标准库；不使用服务端和云服务；不修改用户原始记录。
MVP：导入交接记录、列出记录、按文本检索、显示来源和待办状态；无多人实时编辑。

这些是设计输入，不是经过访谈验证的市场需求。没有真实用户数量、市场规模、付费或性能数据。
provided 模式只分析此材料及本目录内容，不做联网调研、不声称竞争格局已被确认。
live 模式需查询当前公开竞品和替代方式，记录来源及查阅日期；最多比较两个有代表性的对象，保留未知项。

每份阶段文档控制在约 500 字以内，最终设计文档约 1000 字以内，图用内联 Mermaid。
