# Moved to Praxis

The standalone GUI/browser Agent Runtime is now the independent **[Praxis](https://github.com/xiangguangxin/Praxis)** project.

```bash
python -m pip install git+https://github.com/xiangguangxin/Praxis.git
praxis --help
```

See the [Praxis runtime guide](https://github.com/xiangguangxin/Praxis/blob/main/RUNTIME.md), [migration notes](https://github.com/xiangguangxin/Praxis/blob/main/MIGRATION.md) and [OpenAS integration guide](../../plugins/openas/integrations/computer-use/RUNTIME.md). Runtime source, tests and CI are no longer located here.
