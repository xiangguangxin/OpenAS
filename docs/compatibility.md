# 兼容性与记录格式

| 组件 | 当前要求 / 范围 |
| --- | --- |
| Python 脚本 | Python 3.10+；CI 使用 3.10，记忆锁和进程组依赖 POSIX，面向 Linux / WSL |
| JavaScript 测试与示例 | Node.js 22；使用标准模块，不需要 npm 安装项目依赖 |
| Claude 原生插件 | 以本地 CLI 的插件命令为准；本次环境未提供 Claude，未宣称全生命周期验收通过 |
| Claude 热加载集成测试 | 测试要求 CLI >= 2.1.268，并检查同进程、同 session 的原生 reload 证据；需要单独登录与额度 |
| Codex 适配器 | 需要支持 `exec --ephemeral --output-schema -o --sandbox` 的已登录 CLI；2026-10-22 用 0.162.0-alpha.17.2 完成分页任务闭环和三项技能行为评测 |
| GitHub 门禁脚本 | 需要已认证的 `gh` 与目标仓库 Administration 权限；默认只打印计划，不修改设置 |

上述客户端观察只对应所记录版本，不代表全部旧版或未来版本均受支持。测试脚本不会自动登录、升级客户端或扩大沙箱权限。

## 升级到 0.3.0

插件资源通过 marketplace 版本更新或本地目录 reload 应用，项目记忆不被覆盖。

- **工作流快照**：文件值从单个 SHA-256 字符串改为 `{ "type": "file", "mode": 420, "sha256": "…" }`。`mode` 为 POSIX 权限的十进制数（420 对应 0644）。旧历史报告保留原样，外部读取工具需按记录形状区分。
- **记忆证据**：原有 JSON 证据继续有效，只校验直接 JSON 文件。非 JSON 原始来源应通过 `sources` 显式关联，重新提议并审查；不要原地改写旧指纹冒充重新验证。
- **产物目录**：`artifacts` 为可选相对目录列表，默认空。目录在开始时必须不存在，不能覆盖 scope、现有源码或 Git 元数据。新运行应使用干净的任务工作区；不自动删除上次产物。
- **状态恢复**：0.3.0 及更早的历史状态用于审计；0.4.0 的新格式支持下述显式恢复。
